## 3. Academic Evaluation Context

THREATLY was developed as an advanced cybersecurity and full-stack software engineering project demonstrating:
- Multi-vector threat analysis algorithms (URL phishing & malware heuristics, email header/body spoofing analysis, SMS/message social engineering detection, QR code payload extraction & verification).
- Modern web security principles (Defense-in-depth, Content Security Policy with nonces, HTTP Strict Transport Security, Role-Based Access Control, rate limiting against brute force, and bcrypt DoS mitigation).
- Production-grade enterprise software architecture utilizing Next.js 16 (App Router), React 19, TypeScript, Prisma ORM, and PostgreSQL.
- Rigorous automated testing and validation methodologies (unit test suites, regression test suites, isolation verification).
