# THREATLY — Application Screenshots & UI Showcase

This directory is designated for high-resolution application screenshots, workflow captures, and demonstration assets for THREATLY.

---

## Recommended Screenshots to Capture

When running the application locally (`npm run dev`) or in production, capture and place the following images in this directory to enrich the visual showcase:

| Filename | View / Workflow | Description |
|---|---|---|
| `01-landing-hero.png` | Landing Page (`/`) | Hero section with interactive cyber grid, live statistics overview, and CTA buttons. |
| `02-threat-radar.png` | Landing Page / Radar | Dynamic canvas-based Threat Radar component showing visual radar sweep and active telemetry events. |

## Guidelines for Adding Images
- Use lossless PNG format (`.png`) for crisp rendering of typography and charts.
- Recommended resolution: 1920x1080 (1080p) or 2560x1440 (1440p) at 2x scaling.
- Keep filenames consistent with the table above so markdown documentation links remain functional.
